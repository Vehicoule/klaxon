## Detailed Decision Log

### Decision 1: Benchmark Fairness & Cross-Framework Methodology
- **Problem**:
  1. [`bench/runners/flutter/lib/harness.dart`](file:///Users/btw/Documents/projects/Klaxon/bench/runners/flutter/lib/harness.dart#L303-L307) called `ro?.markNeedsPaint()` every tick on static scenes, and [`bench/runners/qt/src/main.cpp`](file:///Users/btw/Documents/projects/Klaxon/bench/runners/qt/src/main.cpp#L357) forced `grabWindow()`/`view.update()`, while Klaxon's [`Renderer.paintDamage`](file:///Users/btw/Documents/projects/Klaxon/src/golden.zig#L224-L233) returned immediately on undamaged frames — producing synthetic `21.3M FPS` numbers for Klaxon on static scenes.
  2. On `shapes_ramp`, `paths_ramp`, and `text_ramp`, Klaxon used a 1-node `SpriteAtlas` + `drawAtlas` (2–3 draw calls) while Compose and Qt instantiated 3,200 layout/widget nodes.
  3. Flutter's [`video_playback.dart`](file:///Users/btw/Documents/projects/Klaxon/bench/runners/flutter/lib/scenes/video_playback.dart#L73-L109) computed 230,400 bytes in a CPU loop and discarded the buffer before running a shader + 45 scanline rects.
- **Decision**:
  - Allow all 4 frameworks to use their natural retained/damage-skip behavior on static scenes.
  - Unify `shapes_ramp`, `paths_ramp`, and `text_ramp` across all 4 frameworks to use idiomatic canvas batching.
  - Remove the unused CPU loop penalty from Flutter's `video_playback.dart`.

### Decision 2: Native Binary Size (`kx_font_wasm.h`) & WAMR Removal
- **Problem**:
  1. Native macOS `hello` and `bench` binaries reached **20.2 MB** (> 4× the `< 5 MB` hard gate in [`docs/PERF-BUDGETS.md`](file:///Users/btw/Documents/projects/Klaxon/docs/PERF-BUDGETS.md#L107)), in part because [`kx_skia/src/kx_font_wasm.h`](file:///Users/btw/Documents/projects/Klaxon/kx_skia/src/kx_font_wasm.h) (4.02 MB) was unconditionally compiled into native builds.
  2. Despite [`ADR-0006`](file:///Users/btw/Documents/projects/Klaxon/docs/adr/ADR-0006-wasm-plugins.md#L14) stating *"No WAMR in the framework"*, [`scripts/fetch-deps.sh`](file:///Users/btw/Documents/projects/Klaxon/scripts/fetch-deps.sh#L231) and [`tools/klaxon/main.zig`](file:///Users/btw/Documents/projects/Klaxon/tools/klaxon/main.zig#L408-L414) still built and required `libiwasm.a`.
- **Decision**:
  - Guard `kx_font_wasm.h` behind `#ifdef __EMSCRIPTEN__` and use OS system fonts on native targets with runtime disk-asset font loading for deterministic golden tests.
  - Remove WAMR from `scripts/fetch-deps.sh` and `klaxon doctor`.

### Decision 3: Platform Layer (`src/platform/`) & C ABI Contract (`klaxon.h`)
- **Problem**:
  1. Layer 4 (`src/platform/`) in [`docs/ARCHITECTURE.md`](file:///Users/btw/Documents/projects/Klaxon/docs/ARCHITECTURE.md#L95-L115) did not exist on disk.
  2. [`ADR-0009`](file:///Users/btw/Documents/projects/Klaxon/docs/adr/ADR-0009-c-abi-contract.md#L13) required a single `klaxon.h` header with layout verification tests, which was missing.
- **Decision**:
  - Create `src/platform/` modules (`storage/kv.zig`, `storage/paths.zig`, `net/http.zig`, `os/window_insets.zig`, `os/url.zig`, `os/haptics.zig`, `os/file_picker.zig`, `os/share.zig`, `os/notifications.zig`, `media/video.zig`, `runtime/plugin.zig`) while keeping root re-exports intact.
  - Create `include/klaxon.h` with compile-time/test-time ABI struct layout assertions.
  - Update `docs/STATUS.md`, `docs/DEVIATIONS.md`, `docs/ARCHITECTURE.md`, and `gates/thresholds.json`.

### Decision 4: GPU Backends & HiDPI / Retina Scaling
- **Problem**:
  1. `kx_begin_frame` ([`kx_skia_common.cpp`](file:///Users/btw/Documents/projects/Klaxon/kx_skia/src/kx_skia_common.cpp#L1620-L1641)) wiped `offscreen_pools`, texture `images`, and the 2048×2048 `atlas` every frame on Vulkan, Dawn/D3D12, and WebGPU because those backends created a transient `skgpu::graphite::Recorder` per frame.
  2. On iOS Graphite-Metal, `kx_begin_frame` reset `ctx->canvas->setMatrix(SkMatrix::I())` after `gpu_begin_frame` scaled the canvas, while `Host.renderFrame` skipped `kx_scale` — leaving iOS at 1× scale.
  3. `kx_offscreen_acquire` allocated offscreen caches at unscaled 1× logical dimensions on HiDPI displays.
  4. `kx_skia_ios.mm` used two unsynchronized `MTLCommandQueue`s; `kx_skia_macos.mm` and `kx_skia_ios.mm` leaked `+1` Metal/CoreFoundation objects under `-fno-objc-arc`.
- **Decision**:
  - Persist `skgpu::graphite::Recorder` at context lifetime on Vulkan, Dawn/D3D12, and WebGPU and remove the per-frame cache/atlas wipe.
  - Apply root HiDPI scaling uniformly after `kx_begin_frame` and scale offscreen surfaces in `kx_offscreen_acquire` by `display_scale`.
  - Share a single `MTLCommandQueue` on iOS, fix MRC retain counts, fix RTL sub-run ordering in `shape_line_runs`, fix Linux font directory scanning, and fix the `kx_atlas_alloc` free-slot leak.

### Decision 5: 6-Platform Accessibility & Modal Focus/Semantics Trapping
- **Problem**:
  1. `kx_a11y_free_string` in [`src/a11y_bridge.zig`](file:///Users/btw/Documents/projects/Klaxon/src/a11y_bridge.zig#L64-L71) freed `ptr[0..len :0]` instead of the `ArrayList` allocation capacity.
  2. macOS `g_root` was never attached to `NSWindow`/`NSView`; iOS ignored `KX_A11Y_CONTROL_CHANGED` value updates; Android called Zig functions from the Java UI thread without synchronization and flattened the tree; Windows lacked `IRangeValueProvider`; Linux ignored `ATK_XY_SCREEN`; Web truncated 64-bit `VIRTUAL_PTR_BIT` IDs past `Number.MAX_SAFE_INTEGER`.
  3. Open modals (`Dialog`, `BottomSheet`, `SideSheet`) did not trap `Tab` focus or background semantics.
- **Decision**:
  - Fix all 6 platform accessibility bridges end-to-end, use `toOwnedSliceSentinel(0)` in `src/a11y_bridge.zig`, and trap focus/semantics to the active modal overlay in `src/ui/semantics.zig`.

### Decision 6: Core UI Engine, M3E Widgets, Declarative Registry & Build/CLI
- **Problem**:
  1. `src/widgets/i18n.zig` allocated `base.text` with `i18n.allocator` and freed it with `node.allocator`.
  2. `src/widgets/carousel.zig` had a UAF on `deinit` (missing `cancelChannel`) and a stack OOB panic when `large_count > 14`.
  3. `ListView` and `Image` did not check `ctxSerialAlive` before destroying cached images; `BuildCtx.rollback` left dangling pointers in `radio_groups`; `textFieldWith` had duplicate `errdefer`s; `ColorPicker` reset alpha to `1.0` on `#RRGGBB` hex commit; `TextField` and `SearchBar` lacked single-line horizontal scroll; `Navigator.navigateTo` ignored query strings; `DevTools.recordFrame` recorded idle `cadence_ms` instead of `dt_ms`.
  4. `build.zig` omitted `mcu_sources` on Web/iOS/Android and ignored `-Dapp-root` on Web/iOS/Android; `klaxon create` omitted `test`/`test-golden` steps.
- **Decision**:
  - Fix all UI engine, widget, DevTools, `build.zig`, `tools/klaxon/main.zig`, and `gates/device.sh` bugs, register all 16 missing widgets in `src/registry.zig`, and enable `.measure_pure = true` across pure widget VTables.
